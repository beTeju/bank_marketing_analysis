# bank_marketing_analysis
End-to-end bank marketing analytics project using Python and R, covering exploratory data analysis, statistical hypothesis testing, feature selection, classification modelling, and model evaluation.

ML Analytics Project

Question: Can we predict whether a bank customer will subscribe to a term deposit after a marketing campaign, and which customer characteristics are most strongly associated with subscription?

Data Source: UCI Machine learning repository - https://archive.ics.uci.edu/dataset/222/bank+marketing
Moro, S., Rita, P., & Cortez, P. (2014). Bank Marketing [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306.
License: CC BY 4.0

Description: The data is related with direct marketing campaigns of a Portuguese banking institution. The marketing campaigns were based on phone calls. The dataset 'bank-full.csv' has 45,211 observations and 17 columns including the target. The classification goal is to predict if the client will subscribe a term deposit (variable y).
